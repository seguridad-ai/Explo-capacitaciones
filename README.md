# Etapa 3 - Sedes y Proyectos

Actualización funcional para el aplicativo Programación de Capacitaciones.

## Incluye
- Catálogo de sedes conectado a Supabase.
- Catálogo de proyectos conectado a Supabase.
- Crear y editar sedes (ADMIN).
- Crear y editar proyectos (ADMIN).
- Activar/desactivar sin borrar historial.
- Búsqueda y filtro de proyectos.
- Vista restringida por el rol y las políticas RLS ya configuradas.
- Actualización de contadores del dashboard.

## Instalación
Subir a la raíz del repositorio GitHub y reemplazar:
- index.html
- styles.css
- app.js
- config.js

No se requiere ejecutar SQL adicional para esta etapa porque utiliza las tablas `sedes` y `proyectos` creadas en la Etapa 2.
