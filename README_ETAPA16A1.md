# Etapa 16A.1 – Comité SST corporativo

## Corrección
El Comité SST ahora admite cualquier trabajador ACTIVO de la Base de Trabajadores,
aunque pertenezca a un proyecto.

Ejemplo:
- Comité SST corporativo + trabajador Cerro Verde = permitido.
- Comité SST corporativo + trabajador Julcani = permitido.
- Comité SST corporativo + trabajador Lima = permitido.

Los Subcomités SST mantienen la restricción por proyecto:
- Subcomité Julcani + trabajador Cerro Verde = no permitido.

## Instalación
1. Ejecutar en Supabase:
   ETAPA16A1_COMITE_CORPORATIVO_PERSONAL_PROYECTOS.sql

2. Debe devolver:
   Etapa 16A.1 aplicada correctamente

3. Reemplazar en GitHub:
   - index.html
   - app.js

4. Esperar GitHub Pages y presionar Ctrl + F5.
